# Etsy listing

She uploads listings by hand, so every folder needs the same seven images in the same order and
a copy file ready to paste. Read these memory notes first for the current scripts and rules:
listing image order, listing images set 3, straight centered cover, hand mockup scale, phone
mockup listing image, Etsy copy voice, Etsy AI policy, and Etsy terms.

## Images (file names in every listing folder)

1. `1-cover.jpg`: one invite, straight (angle 0), centered, on matte cardstock; lift dark cards
2. `2-held-in-hand.jpg`: the hand at true scale to a 5x7 card (use the hand5 or hand6 assets)
3. `3-edit-in-canva.jpg`
4. `4-mobile-digital-invite.jpg`
5. `5-text-message-invite.jpg`
6. `6-what-you-receive.jpg`: includes the props line required by the Etsy AI policy note
7. `7-front-and-back.jpg`

The graphic slides (3 to 6) share one flat background: a light tint of the invite's average
color, with no glow. No separate back-page image. The set-3 scripts in the project's `Claude/`
folder already write these names; older set-2 scripts use old names, so fix them before reuse.
Look at every image before calling the set done.

## Copy

- **Intro:** paint the party and the feeling, using the theme's own language and puns (3, 2, 1,
  blast off; giddy up). Say who it's for and what the day feels like. Mention the card's look
  lightly at most.
- **Then factual sections:** HOW IT WORKS, WHAT YOU CAN EDIT, SIZE, GOOD TO KNOW, and the props line.
- Keep it honest: no matching decor, extra pages, or printing unless included.
- Short sentences. No "Whether you're...", no "elevate", no stacked adjectives, no em dashes.
- No trademarked names in titles, tags, or copy.

Save `listing-copy.md` in the listing folder, and update the copy in the tracker and the set's
copy file so they match (see the copy voice memory for where intros live).

## Finish

Update the Invite and Guide Tracker with the folder path and status, and tell her which folder is
ready to upload.
